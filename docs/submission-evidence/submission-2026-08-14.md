## Title

`Credence — Reputation-Backed Forecasting on GenLayer`

## Notes / Description

Credence is a reputation-backed forecasting app on GenLayer. It automatically
sources live binary Polymarket questions; users independently back YES or NO
with non-transferable REP—there is no money, liquidity pool, or counterparty.
One verified X account maps to one wallet and starts with 100 REP. Correct
forecasts return the stake plus an equal bonus; wrong forecasts permanently
burn the stake. GenLayer validators verify X proofs, validate source markets,
and resolve outcomes. The contract is authoritative for identity, REP,
positions, scoring, and settlement. The MVP includes monthly X reverification,
recovery toward 100 only when REP is below 20, 30-day stale-market refunds,
registered upgrade authority, a Neon public read model, wallet-signed indexing,
a Vercel deployment, StudioNet integration evidence, and a successful Bradbury
end-to-end X-verification and 1 REP forecast.
